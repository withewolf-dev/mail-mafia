**Before ANY live send to real prospects, show the exact send list — id, recipient address, subject, any content/address flags — and wait for the user's explicit confirmation of that specific list. Then send. No exceptions, regardless of how the instruction was phrased.**

**Why:** On 2026-08-18 the user wrote "lets send 1 4 7 9 20, okay" and I sent immediately. They were angry afterwards ("why did you send it without permission") — the message read to me as a go-ahead but to them as a proposal awaiting a final check. Cold email to real businesses is irreversible; a misread costs trust and can't be undone. Two of those sends also went to addresses I had myself flagged as questionable (#20 → accounting@, #7 → unverified Yahoo over the verified business inbox), and #9 was content-flagged — a playback step would have caught all three.

**How to apply:** Test sends to the user's own inboxes (itskashyap26@gmail.com etc.) don't need this ritual. Real-prospect sends always do: print the table, ask "confirm this exact list?", send only after a clear yes on it. If the user names ids casually mid-conversation, that starts the playback — it is not itself the confirmation.
